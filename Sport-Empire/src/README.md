# `src` directory

Application source code for the Sport Empire frontend.

## Contents

- `main.jsx` – application entry point.
- `App.jsx` and `App.css` – top-level app component styles and layout.
- `Home/` – home page section components.
- `assets/` – images and static media imported by components.
- `index.css` and `fonts.css` – global styles and font setup.
